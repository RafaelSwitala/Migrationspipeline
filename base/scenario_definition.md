# Szenario A – Controlled Experiment

Ziel ist die Untersuchung eines KI-gestützten Migrationsprozesses unter kontrollierten Bedingungen.

Rahmenbedingungen:

- Gleicher Prompt für alle KI-Systeme
- Gleicher Kontext (AI-Context-Ordner)
- Keine nachträgliche Optimierung der Prompts
- Gleiche Aufgabenstellung pro Feature

Ziel:

Analyse der Auswirkungen von KI-Unterstützung auf:
- Codequalität
- funktionale Korrektheit
- Migrationsaufwand
