# Comparison Workspace

Hier koennen spaeter featurebezogene Vergleichstabellen zwischen Agenten gesammelt werden.

Empfohlenes Format:

```text
<feature-slug>_comparison.md
```

Diese Dateien sollen aus den jeweiligen `54_research_metrics.md`, `53_test_comparison_report.md` und `55_interpretation_notes.md` der einzelnen Runs gespeist werden.
